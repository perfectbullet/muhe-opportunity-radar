## 使用示例对比

### 场景：市场环境变化重新评估

**第一次分析 (牛市)**:
- 投资者: 巴菲特
- 上下文: "当前处于牛市阶段"
- 结论: "优质企业，但估值偏高，建议等待更好买点"

**重新分析 (熊市)**:
- 投资者: 巴菲特（同一视角）
- 新上下文: "当前转为熊市，估值大幅下降"
- 结论: "优质企业估值已合理，符合安全边际原则，可以买入"

### 场景：多视角对比

**原分析**:
- 投资者: 巴菲特（价值投资）
- 结论: 关注护城河和长期价值

**重新分析（多视角）**:
- 投资者: 巴菲特 + 林奇 + 格雷厄姆
- 结论: 
  - 巴菲特: 优质但偏贵
  - 林奇: PEG 指标合理，成长性好
  - 格雷厄姆: 财务指标稳健
- 综合: 三位大师均看好，可考虑分批建仓
