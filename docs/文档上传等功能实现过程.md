### 🚀 快速使用

#### 1. 安装新依赖
```bash
pip install langgraph pdfplumber python-docx python-multipart
```

#### 2. 测试工作流
```bash
python scripts/test_workflow.py
```

#### 3. 启动 API 服务
```bash
python -m uvicorn api.main:app --reload --port 8080
```

#### 4. 访问 API 文档
http://localhost:8080/api/docs

#### 5. 测试文件上传（使用 curl）
```bash
curl -X POST "http://localhost:8080/api/v1/documents/upload" \
  -F "file=@财报.pdf" \
  -F "investor_id=buffett" \
  -F "auto_analyze=true"
```

#### 6. 测试工作流分析
```bash
curl -X POST "http://localhost:8080/api/v1/documents/analyze-workflow" \
  -H "Content-Type: application/json" \
  -d '{
    "material": "公司：贵州茅台\nPE：35\nPB：12\nROE：30%\n营收增长：15%\n毛利率：92%",
    "investor_id": "buffett",
    "use_workflow": true
  }'
```

```
用户上传文档/输入材料
         ↓
    文档解析节点
    (提取文本内容)
         ↓
    指标计算节点
(PE/PB/ROE/PEG/毛利率)
         ↓
    AI 分析节点
  (投资者视角分析)
         ↓
    结果汇总节点
  (生成Markdown报告)
         ↓
    返回最终报告
```
